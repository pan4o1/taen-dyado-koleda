# Тайният Дядо Коледа

Онлайн версия с колело, Excel/CSV импорт, лични QR кодове и администраторски панел. Данните са в постоянна D1 база (`DB`).

Администраторът влиза с ChatGPT. Сървърът разрешава достъп само за имейла от runtime настройката `ADMIN_EMAIL`, получен през доверения Sites gateway. Не хоствайте Worker директно без тази identity интеграция.

Страницата с колелото получава само QR изображение, без получателя. Първото отваряне на подаръка запазва достъпа в браузъра чрез HttpOnly Secure cookie. Друг браузър получава отказ. Пазете QR кода до първото отваряне. Това защитава първия отворил, без да удостоверява самоличност. Изтриване на бисквитките губи личния достъп.

## Разработка

Node.js 22 или по-нов:

```sh
npm ci
npm run build
npm test
```

`worker.js` и `static/` са изходният код. `build.mjs` генерира самостоятелен Worker в `dist/server/index.js`. Миграциите са в `drizzle/`. Sites workflow качва source commit и пакетира съответстващия build. Runtime тайните се пазят в Sites, извън хранилището.

## Работа

1. Влез през „Администратор“ със своя ChatGPT профил.
2. Зареди `.xlsx`, `.csv` или `.txt` с имената в първата колона: 3–150 различни участници.
3. Създай разпределението и изпрати всеки линк лично на съответния колега.
4. Колегата завърта колелото, сканира кода и отваря подаръка на личния си телефон.
5. Пълното разпределение се вижда само от администратора.

Разпределението е случайна пермутация без подарък към себе си; всеки получава точно един подарък. Версионирането предотвратява едновременно двойно теглене. „Ново събитие“ обезсилва всички предишни покани и QR кодове. QR изображенията се генерират в приложението, без външни QR услуги.
